2. Step-by-Step: How to Deploy Open-Source Suno API (gcui-art/suno-api) for Free

  1. Fork the GitHub Project: Open github.com/gcui-art/suno-api and click Fork to your GitHub account.
  2. Get Your Suno Cookie: Log in to suno.com on Chrome, press F12 → Network tab, refresh the page, click any request to client?_clerk_js_version..., and copy the Cookie value from Request Headers.
  3. One-Click Free Deploy on Vercel: Log in to vercel.com with GitHub, import your forked suno-api repo, add Environment Variable SUNO_COOKIE = (your copied cookie), and click Deploy.
  4. Paste URL Above: Vercel will give you a free URL like https://my-suno-api.vercel.app. Paste it into the Suno API Server URL box above and click Save API Configuration!

3. How to Publish This Website 100% Free on GitHub Pages

  1. Create a free account at github.com and click New Repository named aadhini-raagam (Public).
  2. Click Add file → Upload files, upload this index.html file, and click Commit changes.
  3. Go to Settings → Pages, select Branch: main, and click Save.
